
  # Cybersecurity Dashboard

  This is a code bundle for Cybersecurity Dashboard. The original project is available at https://www.figma.com/design/j3f6QFVeqBjOGScwwZbxCs/Cybersecurity-Dashboard.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm install -D @vitejs/plugin-react-swc` to install the required React SWC plugin for Vite.

  Run `npm run dev` to start the development server.
